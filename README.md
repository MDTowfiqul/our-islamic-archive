# Our Islamic Archive

ইসলামিক রিসোর্স সংগ্রহশালা — লেকচার, সিরিজ, কোর্স, বই, পিডিএফ, অডিও, ভিডিও — সব এক জায়গায়।

Live: https://mdtowfiqul.github.io/our-islamic-archive/

## How it works

- Files live on Telegram: https://t.me/islamic_resource_library
- This repo is the searchable directory. Each resource is one block in `_data/resources.yml`.
- Cards show a Telegram button always, and a Facebook button only when `fb_link` is set.

## Add a resource

1. Post the file in the Telegram group and copy its message link (e.g. `https://t.me/islamic_resource_library/123`).
2. Open `_data/resources.yml` in the repo (web editor), add a block following the commented format at the top of the file.
3. Commit — the site rebuilds in a minute or two.

Categories: আল কোরআন, পিডিএফ ও ইবুক, অনলাইনে ইলম শিখি, ইসলামিক এপস ও সফটওয়্যার, রমাদান ও অন্যান্য.
New categories can be added freely — the filter chips are generated from the data file.
